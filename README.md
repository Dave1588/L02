## ✨ Features

- 🕒 **Real-Time Dynamic Clock**: Accurate live digital clock with animated pulse separators and high-precision second progress visualization.
- 🌅 **Contextual Greeting**: Automatic greeting dynamically customized based on the time of day (*Good morning*, *Good afternoon*, *Good evening*, *Good night*).
- 🌓 **Dark & Light Mode**: Seamless theme switching with local preference persistence (`localStorage`).
- ⏱️ **12H / 24H Format Toggle**: Switch between 24-hour military format and 12-hour AM/PM display with a single click.
- 📊 **Status & Metrics**:
  - Session uptime counter.
  - Day of the year calculator (`Day X / 365`).
  - Automatic local timezone detection (e.g. `Asia/Taipei (GMT+8)`).
- 💎 **Modern Glassmorphism UI**:
  - Animated ambient glowing gradients.
  - 3D interactive tilt effect on cards upon hover.
  - Fully responsive layout for desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup structure.
- **Vanilla CSS3**: Custom design system, CSS variables, glassmorphism, responsive grid & flexbox layouts, smooth micro-animations.

## 🚀 Getting Started

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dave1588/L02.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd L02
   ```

3. **Open the project:**
   Simply double-click `index.html` or open it with your favorite browser / Live Server extension in VS Code.

---

## ⚙️ Deployment to GitHub Pages

To deploy this project to GitHub Pages:

1. Go to your repository on GitHub: `https://github.com/Dave1588/L02`
2. Navigate to **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/(root)`
4. Click **Save**.
5. Your live site will be ready at: `https://dave1588.github.io/L02/`
